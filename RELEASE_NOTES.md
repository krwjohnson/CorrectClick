## 🎉 First release

CorrectClick adds a **CorrectClick** submenu to the Finder right-click menu so you can create new files instantly, wherever you are in Finder — no app windows, no dialogs.

---

## ✨ Features

### New File actions

| Action | Result |
|---|---|
| **New Text File** | Empty `Untitled.txt` in the current folder |
| **New Text File from Clipboard** | `.txt` file pre-filled with clipboard text (RTF stripped automatically) |
| **New PNG from Clipboard** | Clipboard image data saved as `Untitled.png` |

- Filenames auto-increment if one already exists — `Untitled 2.txt`, `Untitled 3.txt`, and so on
- Files immediately enter Finder's inline rename mode after creation, just like creating a new folder

---

## 💻 Requirements

- macOS 13 Ventura or later

---

## 📦 Installation

1. Download `CorrectClick-1.0.0.dmg` below
2. Drag **CorrectClick** to your Applications folder
3. Open CorrectClick — it will prompt you to enable the Finder extension in System Settings
4. Tick **CorrectClick Extension** and you're done

---

## ⚠️ Known limitations
