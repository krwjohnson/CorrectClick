# CorrectClick

Right-click any folder in Finder to instantly create a new file — no app windows, no dialogs.

---

## What it does

CorrectClick adds a **CorrectClick** submenu to the Finder right-click menu with three actions:

| Action | What it creates |
|---|---|
| **New Text File** | An empty `.txt` file |
| **New Text File from Clipboard** | A `.txt` file pre-filled with whatever text is on your clipboard |
| **New PNG from Clipboard** | A `.png` file from an image on your clipboard (screenshots, copied images, etc.) |

Files are named `Untitled.txt` (or `.png`) and automatically renamed to `Untitled 2`, `Untitled 3` and so on if a file with that name already exists. The file is selected in Finder immediately after creation so you can rename it straight away — just like creating a new folder.

---

## Requirements

- macOS 13 Ventura or later

---

## Installation

1. Download and open `CorrectClick.dmg`
2. Drag **CorrectClick** to your Applications folder
3. Open CorrectClick from Applications — it will open **System Settings → Extensions** automatically
4. Tick the checkbox next to **CorrectClick Extension**

That's it. CorrectClick runs quietly in your menu bar and adds the right-click menu to every Finder window.

---

## Usage

Right-click any folder or empty space inside a Finder window and look for the **CorrectClick** submenu.

> **Tip:** "New Text File from Clipboard" and "New PNG from Clipboard" will show a notification if your clipboard doesn't contain the right type of content.

---

## Uninstalling

1. Click the CorrectClick icon in the menu bar and choose **Quit CorrectClick**
2. Open **System Settings → Privacy & Security → Extensions** and untick **CorrectClick Extension**
3. Delete CorrectClick from your Applications folder

---

## Privacy

CorrectClick does not connect to the internet, collect data, or require an account. Everything happens locally on your Mac.
